# Changelog

All notable changes to this application are documented in this file.

## 0.1.0

- Segments with conditions on linked records (count, sum, average, minimum, maximum), on people's own fields and on list membership, combined with ALL and ANY
- Dynamic segments recalculated every 15 minutes and when they change; static segments calculated once
- Members kept in a Twenty list, without putting back people removed by hand
- Translations into the 33 languages Twenty supports
